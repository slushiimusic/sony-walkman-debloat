# sony-walkman-debloat

Tweaks for the Sony NW-WM1AM2 Walkman (Android 11).

- [`classipod/`](classipod/): patches for the Classipod player. They:
  - fix the charging indicator;
  - add a Battery settings screen (Battery Saver, Battery Care, Bluetooth
    scanning, screen timeout);
  - add an option to use Classipod as the home screen;
  - turn off Impeller, which crashes on the Walkman's GPU.

  GitHub Actions builds the APK.
